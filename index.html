Chrome origin trial · 2025

Render live HTML inside a canvas.

A new Chrome capability lets you draw a fully interactive DOM subtree into a <canvas> with context.drawElement(). This site is a sandbox of small, focused demos that explore what that unlocks — from reflections and warps to game HUDs and live mini-maps.

How this site is laid out

Each demo is a single self-contained HTML file under /examples. The shared chrome (sidebar, hero, cards) lives in /assets/styles.css and is reused on every page. Demos that require the origin trial token can declare it in a <meta> tag at the top of the file.
