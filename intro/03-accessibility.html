    Why this is impossible with canvas alone
    
          
    
            A form drawn with fillText is a single opaque <canvas> node
            to assistive tech — one anonymous "canvas" with no fields, no labels, no values. A screen
            reader user simply cannot fill it out. Here, because the form is real DOM that merely
            happens to be painted by the canvas, the entire accessibility tree survives: the
            <fieldset>/<legend> grouping, every
            <label>, roles, values, and the tab order. The inspector above is built
            live from that DOM — nothing here is faked.
