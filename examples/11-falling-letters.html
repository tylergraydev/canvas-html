Falling letters

Click the input and start typing. Each keystroke spawns a real <span> that drops in with gravity, spins on its way down, and slams the input on landing. The input shakes, sparks scatter, the character actually gets inserted — and it's all driven by drawElementImage().

What's happening on a keystroke

keydown fires, we preventDefault() so the input doesn't update yet, then a styled <span> is appended to the canvas with the pressed character. Each frame, its physics state (position, velocity, spin) updates and drawElementImage() stamps it. When it reaches the input's Y, we insert the character via setRangeText, push an entry into a "shake" buffer (which offsets the input's drawn position for ~300ms), and spawn a burst of spark particles.
