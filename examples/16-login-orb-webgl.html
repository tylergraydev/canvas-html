3D login orb (WebGL)

The same idea as example 15, but rendered in a real 3D pipeline. HTML-in-Canvas isn't limited to 2D — WebGL exposes texElementImage2D(), which uploads the live, interactive sign-in form straight to the GPU as a texture. It's mapped onto an actual sphere mesh with perspective, depth, and shader lighting — smooth at the limb, no triangle seams. Hit Rest to bring it front and type on the ball.

2D and 3D, same trial

The HTML-in-Canvas origin trial adds an entry point to both canvas APIs: the 2D context gets drawElementImage() (used in example 15), and the WebGL / WebGL2 contexts get texElementImage2D(target, level, internalformat, format, type, element) — the texture-upload counterpart used here. We generate a UV sphere, spin and tilt it with a model matrix, and a fragment shader draws the orb body, a procedural meridian/parallel grid, per-pixel lighting and a fresnel rim, then samples the form texture over a patch of the surface. Because the form is a real layoutsubtree child, we still pin its DOM hit-box with a transform while it faces front, so the fields stay focusable.
