Polyglot rich text

The WICG spec's complex-text torture test, dialled up. A single block of everything the browser can lay out — bold and links, emoji, a right-to-left Arabic phrase, vertical Chinese, an inline <svg>, an <img>, OpenType ligatures, and a live text input — painted into a rotating, scaling canvas with one drawElementImage() call. The glyphs stay razor-sharp at any angle, and the input is still focusable on the tilt. Try typing in it.

Layout you can't fake with fillText()

Drawing internationalised text into a canvas the old way means reimplementing the browser's text engine: bidi reordering, shaping, vertical writing modes, emoji, ligatures. Here the browser does all of it, and drawElementImage() snapshots the result. Because CSS transforms on the source element are ignored when drawing, the rotation and scale come from the canvas's transformation matrix (ctx.rotate() / ctx.scale()); the element is drawn centred with negative-half-size coordinates. The returned matrix is written back to the block's transform so the live DOM — including the focusable input — lines up with the painted, tilted pixels.
