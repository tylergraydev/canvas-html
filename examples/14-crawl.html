Title crawl

A 3D-perspective scrolling title crawl. The text is a real, scrolling DOM element uploaded to the GPU with gl.texElementImage2D() and rendered on a tilted plane in WebGL — so it genuinely recedes toward a vanishing point. Edit the textarea or fetch a script from a URL to put anything on screen.

How the perspective works

The text scrolls flatly inside an overflow:hidden window (a real DOM element). Each frame, gl.texElementImage2D() uploads that window to a GPU texture, and a vertex shader maps it onto a plane tilted back toward a vanishing point. A fragment-shader fade dims the text as it recedes. Because the texture is only the visible window, scripts of any length stay GPU-friendly.
