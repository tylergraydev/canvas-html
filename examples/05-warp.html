How the bands work

Each band sets a horizontal clip rectangle on the canvas, translates by a sine-wave offset, then calls drawElementImage(). Only the pixels inside that clip survive — the next iteration draws the next band, with a different offset. Stacked, they form a continuous warped image. The DOM hit-box uses the un-warped (centred) copy so buttons still click.
