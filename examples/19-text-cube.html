Spinning text cube (WebGL)

The WICG webGL sample, expanded into a tumbling cube. Each of the six faces is a different live DOM panel — a title, a ticking clock, emoji, mixed-script text, a CSS bar chart — uploaded straight to the GPU with texElementImage2D() and mapped onto real cube geometry with perspective and shader lighting. Panels are rasterised only when they change (the clock re-uploads once a second), so the tumble itself is pure GPU work. No matrix library — the math is a few dozen lines of hand-rolled mat4.

One texture per face, uploaded on change

The cube is 24 vertices (4 per face) with per-face UVs and normals. texElementImage2D(target, level, internalformat, format, type, element) is the WebGL counterpart of drawElementImage(): it uploads a live element as a GPU texture. We keep six textures and re-upload a face only when its panel changes — the clock dirties itself once a second; the rest upload once and never again — so per-frame cost is just six textured quads and the lighting shader. Unlike the 2D path, WebGL returns no transform for hit-testing, so these faces are display-only and marked inert; see example 16 for the technique that pins a live, typeable form onto a 3D surface.
