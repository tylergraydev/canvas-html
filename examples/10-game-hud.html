Why composite HUD this way

Normal HTML HUDs sit in a sibling layer above the game canvas — fine, but the canvas can't see them, so they can't be part of effects (blur, fade, post-processing, screenshots). Painting them into the canvas via drawElementImage() keeps them on the same surface — and they're still real DOM, so the buttons still click.
