The API, in 6 lines

const ctx = canvas.getContext('2d');

canvas.onpaint = () => {
  ctx.reset();
  // draw your own backdrop, then the element
  const t = ctx.drawElementImage(card, 0, 0);
  card.style.transform = t.toString();
};

onpaint fires when the canvas needs to repaint — DOM mutations inside it, user input, focus changes. The returned transform tells the browser where the element layer sits so clicks and focus rings still land in the right pixels.

What's happening

The <canvas layoutsubtree> attribute opts the canvas into laying out its DOM children. Inside onpaint we wipe the canvas, draw a backdrop, then call drawElementImage() on the child element — which paints the element's current visual state into the bitmap. We assign the returned transform back to the element's style.transform so the hit-test geometry of the live DOM lines up with the painted pixels.
